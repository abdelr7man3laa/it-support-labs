# Basic PC Hardware Troubleshooting

## Purpose

Document basic hardware checks practiced during my CompTIA A+ course.

## Safety

- Shut down the computer before opening the case.
- Disconnect the power cable before handling internal components.
- Follow basic ESD precautions when working with components.
- Do not open a power supply unit.

## Basic Checks

1. Confirm that the power cable and display cables are connected securely.
2. Check that the monitor is powered on and set to the correct input.
3. Look for visible damage or loose connections.
4. If the PC does not start, check the power connection and basic power indicators.
5. If the PC starts but has no display, check the monitor, display cable, and selected input.
6. If working inside the PC, verify that accessible components and cables are seated correctly.
7. Restart the computer and note any error messages or unusual sounds.

## Training Note

These are basic course-practice checks, not professional work experience. Hardware troubleshooting should be performed only on equipment you are authorized to handle.
