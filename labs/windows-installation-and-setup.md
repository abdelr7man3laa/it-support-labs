# Windows Installation and Setup

## Purpose

Document the Windows installation and initial setup tasks practiced during my CompTIA A+ course.

## Preparation

- Confirm the computer meets the Windows installation requirements.
- Back up important files before installation.
- Prepare installation media using an authorized Windows source.
- Confirm the correct boot device and installation target.

## Installation and Setup

1. Boot the computer from the installation media.
2. Follow the Windows setup prompts and select the appropriate language and region.
3. Choose the installation type and target drive carefully.
4. Complete the initial Windows setup.
5. Review Windows Update and install available updates.
6. Check Device Manager for devices with missing drivers.
7. Confirm that the network, display, audio, keyboard, and mouse work.
8. Record any issues and how they were resolved.

## Verification Checklist

- Windows starts successfully.
- The computer connects to the network.
- No unexpected warning icons appear in Device Manager.
- Windows Update status has been reviewed.
- Basic peripherals work as expected.

## Training Note

This document describes course practice. It does not represent professional work experience. Back up data and confirm the target drive before installation, since installation can erase files.
