# IT Support Labs

Hands-on practice completed as part of my CompTIA A+ course. This repository documents training exercises in IT support and troubleshooting.

## Labs

### 1. PC Hardware
- Practiced assembling and disassembling a desktop PC.
- Identified common computer components and their functions.
- Followed basic hardware safety practices.

### 2. Windows Installation and Setup
- Practiced installing and configuring Windows.
- Reviewed initial setup and basic system settings.

### 3. Hardware and Software Troubleshooting
- Practiced diagnosing common PC hardware and software issues.
- Followed a basic troubleshooting process to identify possible causes and solutions.

### 4. Printer Support
- Practiced printer setup and basic troubleshooting.

### 5. Basic Networking
- Practiced basic network setup and connectivity checks.
- Reviewed common network devices, cables, and connection issues.

### 6. User Accounts and Permissions
- Practiced setting up user accounts.
- Reviewed basic account and permission management.

## About This Repository

These are training exercises completed during my CompTIA A+ course. They represent hands-on course practice, not professional work experience. I have completed the course, but I have not taken the official CompTIA A+ certification exam.
